# AI-Based Football Player Tracking and Performance Analysis

An AI-powered football video analysis system that detects and tracks players from match footage, generates player-focused tracking videos, and provides basic movement analysis.

## Project Status

🚧 Under Development

## Planned Features

- Team management
- Player management
- Match management
- Manual lineups
- Football game format configuration
- Match video upload
- AI player detection
- Multi-player tracking
- Individual player tracking video
- Movement analysis
- Player heatmaps
- Performance dashboard

## Technology Stack

- Python
- FastAPI
- React
- PostgreSQL
- YOLO
- ByteTrack
- OpenCV
- FFmpeg
